# 크레딧·비공식 고지 초안 (B30용, 데이터 파일 내용의 초안)

본 소프트웨어는 개인이 제작한 비영리 팬 애플리케이션이며, 각 캐릭터의 권리자와 무관한 비공식 작품입니다.
등장하는 도트 스프라이트와 대사는 모두 제작자가 자체 창작한 2차 창작물이며, 공식 일러스트·로고·음성은 사용하지 않았습니다.
